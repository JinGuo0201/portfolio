# 博士申请汇报演示（PHDPresentation）

个人学术汇报用的网页版幻灯片，独立于本站主站（`/index.html` 等），互不影响。

- 入口：`phd-presentation/index.html`
- 尺寸：1920×1080 舞台，随窗口等比缩放
- 操作：`←` / `→`、`PageUp` / `PageDown`、`空格` 翻页；`Home` / `End` 首末页；`F` 全屏
- 打印 / 导出 PDF：`Ctrl+P`（每页一张 1920×1080 横向纸）
- 调试参数：`?p=N` 直接打开第 N 页；`?shot=1` 隐藏 UI 且动画直达终态（截图用）；`?film=1` 仅隐藏 UI
- 依赖：`assets/`（照片、校徽、插画、点阵地图、论文二维码、Inter 字体），全部相对路径引用

页面结构：封面 → Agenda → Overview → Researches → Projects → Skills → 研究计划（DEMO 占位）→ Thank you → Q & A → Backup。
